# ModusToolbox™ Machine Learning ExecuTorch Asset Release Notes

The ModusToolbox™ ML ExecuTorch asset provides the ExecuTorch runtime integration used by the ModusToolbox™ Machine Learning middleware backend.

## What's Included?

Refer to the [README.md](./README.md) for a complete description of the ModusToolbox™ Machine Learning ExecuTorch asset.

## What Changed?

### v1.2.0

* Initial ModusToolbox™ asset release for ExecuTorch runtime integration
* PSOC™ Edge ARM Cortex-M55/Ethos-U55 as target device

**Provided Features:**
* Ethos-U55 backend delegate
* `cortex_m` quantization/dequantization operators
* ExecuTorch `portable` kernels
* Infineon PSOC™ Edge-compatible logging implementation
* ModusToolbox build configuration

## Supported Software and Tools

This version of the asset was validated for compatibility with the following Software and Tools:
